Method

90 s plays, content insane_newer_p200_h264 (ladder 360p→2160p). iphone-sim: each cell run 3× (4 cells in parallel across 4 Fleet sims); iphone (real hardware): n=1. Metrics from harness query events; residency/startup-eff integrate the rendition series over the first 60 s (non-playing = 0). CoV = stdev/mean across the 3 reps. Reading it

Startup-eff is a bitrate-utilization proxy, not a perceptual QoE score (ITU-T P.1203/P.1204 and VMAF are the rigorous alternatives; video-start time is industry-standard, CTA-2066/CMCD). The 0.8 Mbps limit row is omitted (out of range). The real iphone was swept before the 20 Mbps limit was added, so it has no 20 Mbps rows.
